# НашеПО · Создание проекта для Топоматик 360

Версия 0.1.3. Плагин открывает сразу несколько файлов в одном проекте. Первый выбранный файл открывается как проект, остальные подключаются к нему вложениями, каждое на своём слое с именем файла. Ручное добавление файлов в дереве проекта больше не требуется.

## Установка

Адрес плагина:

    https://borismoniac.github.io/360.ProjectFiles/

В настольном Топоматик 360 откройте **Плагины → Установить плагин**, вставьте этот адрес и подтвердите установку. После первой установки перезапустите приложение. В веб-версии обновите страницу Топоматик 360. Затем откройте на ленте вкладку **НашеПО**.

[**Открыть установку в веб-версии Топоматик 360**](https://360.topomatic.ru?extensionInstallPath=https%3A%2F%2Fborismoniac.github.io%2F360.ProjectFiles%2F)

## Команды

Вкладка ленты **НашеПО**, группы **Проект** и **Вложения**.

- **Создать проект** — открывает диалог выбора файлов с множественным выбором. Первый файл открывается как проект, остальные подключаются вложениями. Если проект уже открыт, плагин спросит, создать новый или добавить файлы в текущий.
- **Добавить файлы** — подключает выбранные файлы к уже открытому проекту.
- **Обновить вложения** — перечитывает все вложения текущего проекта с диска.
- **Состав проекта** — выводит список вложений с адресами и состоянием загрузки.

Те же команды продублированы в меню **НашеПО**.

## Как это работает

Плагин использует штатный механизм вложений Топоматик 360. Для каждого выбранного файла:

1. Определяется постоянный адрес файла через закладку рабочей области, с откатом на исходный адрес.
2. Создаётся слой с именем файла, если такого слоя ещё нет.
3. Файл добавляется в таблицу вложений проекта и сразу загружается.

Повторный выбор уже подключённого файла не создаёт дубликат. Ошибка на одном файле не прерывает обработку остальных: итог по всем файлам выводится в канал **Создание проекта** и в сводном сообщении.

## Поддерживаемые форматы

Диалог предлагает фильтры для файлов Топоматик 360, IFC и чертежей AutoCAD, а также вариант **Все файлы**. Фактический набор форматов зависит от установленных в Топоматик 360 редакторов и импортёров. Например, чтение DWG обеспечивает отдельный плагин DWG reader.

## Сборка

```sh
npm install
npm run build
```

Сборка попадает в `dist/` и копируется в `docs/`, откуда её публикует GitHub Pages. Отладка — `npm run serve`, проверка типов — `npm run typecheck`.
